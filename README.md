# Singapore Street Address Reconciliation Service

A local reconciliation service for OpenRefine (W3C Reconciliation API v0.2). It cleans messy Singapore street names with regex, then matches them against a reference dataset using Levenshtein distance and returns ranked candidates with a 0 to 100 confidence score.

| File | What it is |
|---|---|
| `finalServer.py` | The main Flask server. Cleans the query, scores it against the reference dataset and returns matches to OpenRefine. |
| `prepare_dataset.py` | Builds `reference_dataset.csv` from the ACRA file (uppercases, removes blanks and duplicates, adds IDs). |
| `EntitiesRegisteredwithACRA.csv` | Source data (ACRA registered entities). Only the `reg_street_name` column is used. |
| `reference_dataset.csv` | The reference list of street names (`id`, `address`) that the server matches against. Generated by `prepare_dataset.py`. |
| `suggested_addresses.csv` | Queries the server was not confident about (top score below 75), saved for manual review. Generated by the API server. |
| `BusStopChineseNames.csv` | Test data used to try the service in OpenRefine. |
| `new_addresses.csv` | Test data of made-up addresses that are not in the reference dataset. |
| `filter engines test/regex_filter.py` | Unit test for the regex cleaning function `clean()`. |
| `filter engines test/levenshtein_scorer.py` | Test that prints how the similarity score drops as edit distance grows. |
| `README.md` | This file. |

## Datasets to download

The two source CSV files are not stored in this repository (the ACRA file is over 200 MB). Download them from data.gov.sg and put them in the project folder, next to `finalServer.py`, using the exact file names below.

| Dataset | Used for | Download page | Save as |
|---|---|---|---|
| Entities Registered with ACRA (ACRA) | Source for the reference dataset | https://data.gov.sg/datasets/d_3f960c10fed6145404ca7b821f263b87/view | `EntitiesRegisteredwithACRA.csv` |
| Bus Stop Chinese Names (LTA) | Test data | https://data.gov.sg/datasets/d_54592963dbd23464b875379a21c2cfe9/view | `BusStopChineseNames.csv` |

On each page, click **Download CSV**. If the downloaded file has a different name, rename it to match the table.

Notes:

- The ACRA dataset is updated monthly, so a newer download may give a slightly different `reference_dataset.csv` than the one used in the report.
- `reference_dataset.csv` is generated from the ACRA file by `prepare_dataset.py`, so you only need the ACRA file if you want to rebuild it.

## How to run

1. Install the requirements:

   ```
   pip install flask python-Levenshtein pandas
   ```

2. Build the reference dataset (only needed if `reference_dataset.csv` is missing or the ACRA file changes):

   ```
   python prepare_dataset.py
   ```

3. Start the server:

   ```
   python finalServer.py
   ```

4. In OpenRefine, choose **Reconcile -> Start reconciling -> Add Standard Service** and enter the URL the server prints, for example `http://localhost:5000/reconcile` (if `localhost` fails, use the machine's local network IP shown in the terminal, such as `http://192.168.0.225:5000/reconcile`).

## Quick test without OpenRefine

Open this in a browser to see the cleaned query and its top matches:

```
http://localhost:5000/search?q=Blk 10 Maple Rd
```
